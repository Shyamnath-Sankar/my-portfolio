THE BRIEF

Feedback only matters if it can become change.

EduEcho gives students a structured, easy way to share feedback while giving a large institution an operationally simple source of truth. It is a system built to make the signal clearer for everyone involved.

THE BUILD

From messy records to a usable operating system.

The hard work was not only the feedback flow. It was the underlying data model. An automated ETL pipeline transforms bulk institutional Excel records into a relational SQL database with dynamic staff-to-department mapping.

  • Campus-wide evaluation platform, live at V.S.B. Engineering College
  • Automated Excel-to-SQL institutional data pipeline
  • Dynamic staff, department, and metric mapping
  • Made for a single operator to manage at scale
